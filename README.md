# 🏋️ Personalized Workout Planner

Personalized Workout Planner is a user-friendly fitness assistant designed to help individuals create custom workout plans based on their personal goals and preferences. With a clean interface and intuitive flow, the app collects basic inputs like name, age, weight, and desired workout duration to generate tailored routines. Whether you're a beginner or a fitness enthusiast, this planner adapts to your needs and keeps your progress accessible.

## 🧩 Overview

This app helps users generate personalized workout plans by collecting basic inputs like age, weight, and preferred duration. The interface is clean, responsive, and built for ease of use.

---

## 💡 Features

- 🎯 Personalized fitness planning
- 🧘 Input fields for age, weight, and workout duration
- 🕒 Default 30-minute medium intensity option
- 📱 Responsive design with modern UI
- ⚡ Powered and deployed via Vercel
